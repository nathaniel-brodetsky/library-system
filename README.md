# Бібліотечна система

Програмна система керування бібліотечним фондом (C++, CMake), що використовується як об'єкт дослідження в лабораторних роботах з дисципліни «Якість програмного забезпечення та тестування».

## Збирання

```bash
cmake -S . -B build
cmake --build build
./build/library_legacy
```
